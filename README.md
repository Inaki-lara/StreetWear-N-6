# StreetWear - Tienda Online

Sitio web responsive de indumentaria urbana desarrollado con HTML5, CSS3 y Bootstrap 5 para el curso de Desarrollo Web en Coderhouse.

## 🚀 Sitio desplegado
Podés ver el proyecto en vivo acá:
https://inaki-lara.github.io/StreetWear-N-6/

## 🛠️ Tecnologías utilizadas
- HTML5 Semántico
- CSS3 (Variables, Flexbox, CSS Grid y Media Queries)
- Bootstrap 5
- Git y GitHub

## 📄 Páginas incluidas
- Inicio (`index.html`)
- Productos (`pages/producto.html`)
- Nosotros (`pages/nosotros.html`)
- Preguntas Frecuentes (`pages/preguntas.html`)
- Contacto (`pages/contacto.html`)
